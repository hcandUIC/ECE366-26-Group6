---------------------------------------------------- HOW TO RUN PROGRAM ----------------------------------------------------
============================================================================================================================
(1)	Extract all files from the TAR file into the same folder (ensure IsFibonacciOdd.asm, fibs.asm, and is_odd.asm are together)
(2)	Open the MARS program
(3)	In MARS, go to "Settings" at the top and check the following two boxes:
	- "Assemble all files in directory"
	- "Initialize Program Counter to global 'main' if defined"
(4)	Go to "File" then "Open", and open "IsFibonacciOdd.asm"
(5)	In the .data section, change the value of 'n' to the desired nonnegative integer
(6)	Go to "File" then "Save"
(7)	Go to "Run" then "Assemble" (F3). Once assembled, click the green play arrow (F5) to run
(8)	The output value will be stored in the 'result' memory location in the Data Segment
(*)	1 (True) means the nth Fibonacci number is Odd : 0 (False) means the nth Fibonacci number is Even
